Privacy

RuneRadar is a personal map. Your live game data travels directly from RuneLite to your browser on the same computer. It is not uploaded to our website host or a relay server.

When you connect

Clicking Open RuneRadar in the plugin pairs a browser tab and shares your in-game coordinates and floor, account name, world, current HP, prayer and run energy with that tab. No other players' locations, inventory, bank, friends list, chat or login credentials are collected.

The link works once and expires after one minute. It is removed from the address bar immediately. The tab keeps its reconnect credential in memory for up to 12 hours. A new pairing replaces the old one. Refreshing or closing the page removes that tab's credential.

Use Disconnect map in RuneLite or the map settings to revoke the pairing. Disabling the plugin also ends it. Logging out, loading, unsupported instances, stale data or losing the connection clears the displayed location and account details.

Optional helpers

Clue and quest assistance each start off. Their RuneLite settings allow the paired tab to receive the current objective title, instruction and supported map targets. Turning either setting off clears that helper from the map. We do not enable other plugins, perform game actions, or send helper objectives to a hosted service. Quest sharing requires a compatible Quest Helper release; current upstream support is still pending.

What stays in your browser

Theme, marker and other map preferences, plus pins and paths you create, are saved in local browser storage. Live player coordinates, account details, helper objectives and pairing credentials are not written there. Export downloads your saved pins and paths to a file; import reads a file you select locally. Clearing this site's browser data removes its saved preferences and drawings.

The player information panel is visible by default. Hiding it changes the display; use Disconnect map to stop receiving account data. A manually created pin can identify a place you choose to save.

Website requests

GitHub Pages serves the map, images and bundled scripts. Like any website host, GitHub can receive request information such as your IP address, browser details and which static tiles you request. Tile requests can indicate the area being viewed, including while following you; they do not contain your account name, world, stats, exact live coordinates or pairing secret. See GitHub's privacy statement.

This site has no advertising or analytics service. Ordinary map browsing does not attempt a local RuneLite connection. Opening an external link, such as a Wiki page, visits that site's service.
